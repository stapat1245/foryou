# a web rose bouquet 

 inspired and modifief version of @dwcminh.ascii's art


## Open it in a browser

```
make up
```

Then open <http://localhost:8080>. To build and run the same page in Docker:

```
make up
```



## Run it on the desktop

```
pip install -r requirements.txt
python rose_bouquet.py
```

Keys: `Space` pause · `R` restart · `S` save a screenshot
